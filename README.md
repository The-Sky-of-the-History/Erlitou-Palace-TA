// 阶段目标与专业对齐
基于《偃师二里头——1959年～1978年考古发掘报告》，完成宫殿复合体白盒主体落位。本项目旨在对标国风大世界游戏副本Boss作战主场景，重点解决建筑竖向尺度与空间威压感。通过确立主殿、廊庑、北门与东便门的平面位置与竖向高差，为后续进入PBR材质阶段及引擎氛围搭建做准备。

1. 核心方法论：空间秩序与视觉焦点

美术导向的复原探索：采用“XY按外缘尺寸换算工程单位，Z轴按推演真实高度建模”的方式。不套用严格1:1比例尺，而是以玩家视觉体验（第一人称/第三人称巡视）为核心，探索较适合游戏引擎的国风建筑比例。
· 初始基准与视觉引导：锁定廊庑柱高为 2.25m，大殿柱高4.4m。

// 攻坚与复盘：视觉引导与玩家体验

[ 痛点一:  视觉压平与空间叙事缺失 ]

· 现象：初期主殿与廊庑柱高参数统一（2.25m），导致主殿在常规视距与俯视角下被“压平”，完全丧失视觉中心感与威压感。

· 破局：参考官方考古报告，强力上调主殿柱顶高度，拉开与四周廊庑的Z轴高差；同步修正外围廊庑屋顶脊线Z值，避免远景遮挡主殿轮廓。

· 复盘：平面落位只是基础，竖向层级是决定空间叙事（Spatial Narrative）的决定性因素。

[ 痛点二：缺乏工业规范,导致网格穿模 ]

· 现象：早期资产拼接过度依赖视觉拖拽，未锁定坐标基准，导致立柱与台基交接处发生严重穿模与Z-fighting（闪烁），后期修改成本极高。

· 破局：引入坐标数值化管控。搭建前预先锁定台基、墙址的关键Z轴高程；所有立柱、门道强制通过精确数值输入对齐，杜绝肉眼微调。

· 复盘：严格执行坐标约束后，模型接缝实现视觉零瑕疵。模块化搭建（Modular Kitbash）的核心正是底层数学逻辑的精确控制。

// 调试与规范化工作流（向工业化标准看齐）

【工作流迭代：基础搭建与玩家视角验证】

· SOP 1：Select Mode 精准对位：在引擎中使用选择模式进行资产模块化拼接，结合Grid Snap（网格吸附）与坐标输入，从源头控制模型穿插。

· SOP 2：第三人称（TP）体验驱动：切换Third-Person角色在场景内真实跑图，以玩家视距检验建筑高差带来的威压感，排查视线死角。

// 后续迭代计划 (Next Milestones)

1. 东厨落位与白盒收尾：完成最后东厨区域搭建，强制贯彻坐标对位规范，确保Z轴高程对齐，二里头一号宫殿项目宫殿本体白盒全面竣工。

2. 全局复核与工程归档：对复合体进行最后坐标复查，导出锁死参数快照，归档核心建筑平面坐标与关键Z轴高程。

3. TP全路径跑图验收：操控TP角色全动线测试，检验空间连贯性，排查残留穿模与悬浮面，以真实玩家体验验证空间秩序。

4. 白盒结项与PBR预研：宫殿本体白盒收尾后正式进入材质探索。前期西安旅游拍摄的木柱与瓦片素材，因夏商与唐宋明清风格差异较大，无法直接照搬。下一步将提取其风化木纹与陶瓦肌理进行风格适配，结合夯土台基参考，在 Substance 3D Painter 制作写实材质，并在 UE5 Lumen 下搭建光影，为输出国风场景作品集做准备。
