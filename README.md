## 📌 项目简介 (Project Overview)
本项目基于虚幻引擎 5.8 (UE5.8)，依据《偃师二里头》官方考古发掘报告，对二里头遗址宫城建筑群进行考古导向的 3D 环境美术复原。

技术路线确立「考古写实基底 + 国风 NPR 风格化上层」的双轨渲染方案。旨在通过**工业化管线（Industrial Pipeline）**与**模块化搭建（Modular Kitbash）**，验证历史遗迹在现代游戏引擎中的空间叙事与性能表现。

*( 👉 建议：在这里拖拽一张你最满意的 UE5 场景截图或白盒轴测图进来，作为项目封面 )*

---

## 🚀 核心技术栈与工作流 (Core Tech & Workflow)

- **引擎技术**：UE 5.8, Lumen 全局光照, Substrate Toon BSDF (NPR实验性渲染)
- **材质系统**：PBR 母材质统筹，高度实例化 (Material Instance) 参数管控
- **场景搭建**：严格空间坐标对位，大场景 Draw Call 优化 (`Merge Actors`), LOD 预配置
- **开发规范**：标准化资产命名、SOP 技术排错沉淀、版本控制 (Git)
